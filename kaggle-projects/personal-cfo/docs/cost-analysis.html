Full disclosure — assumptions & caveats

  • Token model: ~3,000 input + 550 output per query, 1–3 LLM calls, grounded in orchestrator.py. This is the durable part; prices drift.
  • Judge does 0 LLM calls (rule-based, judge.py) and all math is deterministic (finance_engine.py) — the model only picks tools and writes prose.
  • LLM prices live 2026-08-04: Flash-Lite $0.10/$0.40, Haiku 4.5 $1.00/$5.00, Sonnet 5 $3.00/$15.00 per 1M in/out. Re-pull before quoting.
  • Prompt-caching the static tool-schema prefix (~10× cheaper input) roughly halves the input half of every LLM figure — not applied above, so these are conservative.
  • Infra = GCP estimates, billed by exact usage: Cloud Run + Cloud SQL/Neon + Firebase Hosting/Auth. Ranges midpointed; re-price with the GCP calculator before committing.
  • Lean tier = scale-to-zero + free Postgres/Auth. Production = warm instance + managed DB with backups + email + monitoring.
  • Domain ~$1/mo (a .com at ~$12/yr). One-time build cost is $0 — the code exists.
  • Excludes your own labor, marketing spend, bank-connector/Plaid fees (manual data), and paid analytics.
